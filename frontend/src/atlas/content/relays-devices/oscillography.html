☰The rules, stated plainly

The two shapes

  • Everything recorded is one of two shapes: a triggered waveform snapshot (EVE / CEV / COMTRADE) or a continuous change log (SER, and SOE at the system level). SUM and HIS are the index cards.
  • Waveforms answer what did the signals do. The SER answers what happened first. A complete analysis pulls both.
  • A snapshot only exists if something triggered it — TRIP/TR, the ER equation, or a TRI/TRIGGER command. No trigger, no record.

Oscillography

  • The relay is always buffering; the trigger just freezes a window — PRE cycles of prefault, LER cycles total.
  • Filtered is the relay's eye (triage). Raw is the system's truth (analysis) — DC offset, harmonics, CT saturation only show in CEV R or native COMTRADE.
  • Storage is finite and nonvolatile: new events push out the oldest — and changing LER erases everything stored. Retrieve first, reconfigure second.

1Two kinds of records

Oscillography is a snapshot: analog samples and Relay Word bits for a fixed window around a trigger, nothing outside it. The log runs continuously: one timestamped entry per state change, no waveform. The same disturbance lands in both — differently.

The log catches everything, thinly; the snapshot catches one window, densely. ▶ Animated in the HTML edition.

3Oscillography: anatomy of a capture

All flavors of event report share the same capture machinery — they differ only in formatting and sample treatment. The relay samples continuously into a rolling buffer; a trigger (TRIP/TR, the ER SELOGIC equation, or a TRI/TRIGGER command) freezes a window of it into storage.

Prefault data exists because the buffer was already running — the trigger freezes PRE cycles of the past plus the rest of the window. ▶ Animated in the HTML edition.

5The report flavors

EVE n · EVE R n (raw)EVE — ASCII event report

Human-readable columns straight on the terminal: filtered analogs at 4 samples/cycle plus selected Relay Word bits. Quick sanity check — did the right element pick up? EVE R swaps in raw analogs (16 samples/cycle on the SEL-751A).

CEV n · CEV R (raw) · CEV L (8 s/cyc, 400 series)CEV — Compressed ASCII event report

Same capture, machine-friendly: comma-delimited with checksums, consumed by SynchroWAVe Event and comms processors. Carries all Relay Word bits, plus channels the plain EVE lacks (frequency, arc-flash light on the SEL-751A). Use CEV R for accurate analysis — SEL says so explicitly.

IEEE C37.111-1999 / -2013 · .CFG + .DAT + .HDRCOMTRADE — the interchange standard

Vendor-neutral file set every analysis tool reads. 400-series relays (SEL-451 etc.) record it natively — binary, raw, up to 8 kHz sampling, time-tagged to better than 10 µs — retrieved by FTP/FILE. For relays that only produce ASCII/CEV, SynchroWAVe Event converts to COMTRADE for other tools.

Storage is finite and nonvolatile. The SEL-751A keeps 77 fifteen-cycle or 19 sixty-four-cycle reports; new events push out the oldest. Records survive power loss — but changing LER erases them all, so pull critical events before editing report settings.

8Troubleshooting & fine print

  • An event you can't find may never have triggered. Only TRIP/TR, the ER equation, or a TRI command start a capture — a picked-up-but-never-tripped disturbance needs ER terms (e.g. pickup bits) to be recorded.
  • Summaries are not reports. Auto-messaged summaries (and history rows) are pointers; the stored report is the evidence. Archive the report, not the summary.
  • Some channels only exist in one flavor. On the SEL-751A, frequency and arc-flash light channels appear in CEV, not in plain EVE.
  • Tooling: ACSELERATOR Analytic Assistant (SEL-5601) was discontinued in 2019 — SEL-5601-2 SynchroWAVe Event is its replacement for plotting CEV/COMTRADE records.
