☰The rules, stated plainly

QuickSet discipline

  • Read before you edit, save before and after every change — SEL's own recommendation. The database copy is only the truth if you keep it that way.
  • The settings file must match the relay: part number and Z-number (driver version) both, or the send fails with an error.
  • Sending settings to the active group disables the relay briefly (SEL-751A: up to 5 s on save; <1 s on a group change). Editing a non-active group interrupts nothing.
  • Back up the .rdb — QuickSet keeps only the last three saves beside the file (an _rdb_backups folder); uninstalling doesn't delete it, but off-machine backup is on you. Keep the working copy on a local drive, not a network share — SEL warns of save conflicts and latency corruption (multi-user access belongs in Device Manager).

1What QuickSet is

ACSELERATOR QuickSet (SEL-5030) is SEL's PC-side setting, event analysis, and measurement tool — the standard engineering-access front end for SEL relays. It is driver-based: each relay model and settings version has its own settings driver, selected by the Z-number in the relay's FID string. The suite (as documented for the SEL-751A):

ApplicationWhat it does
Rules-Based Settings EditorOn/offline settings with interdependency checks; manages settings for many devices in a database
HMISummary view of device operation — live metering, targets, control; simplifies commissioning testing
Design Templates (licensed versions)Store standardized settings as templates; lock settings to your standards, or lock and hide unused ones
Event AnalysisOscillography and event retrieval/viewing tools
Setting Database ManagementThe .rdb database of device settings
TerminalDirect ASCII connection (Ctrl+T), with connection logging
HelpGeneral plus device-specific settings help (F1)

You never need QuickSet — every SEL relay is settable from an ASCII terminal or the front panel — but QuickSet adds the rules-based checks, SELOGIC Expression Builder, HMI, event analysis, and the settings library.

2Connecting: the engineering-access session

QuickSet talks to a relay through any of its comm ports (SEL-751A: PORT 1–4 or front-panel PORT F). Connection setup lives under Communications > Parameters:

  • Serial: match the PC COM port to the relay's port settings — 751A serial defaults SPEED := 9600, 8-N-1. Mismatched speed/framing = no prompt.
  • Network: pick Network as the Active Connection Type and enter the IP parameters (751A Ethernet defaults: IPADDR := 192.168.1.2, SUBNETM := 255.255.255.0). The File Transfer Option offers FTP, Telnet, Raw TCP, or SSH; for the 751A, always select FTP.
  • Connection profiles: Save to Address Book stores a named network profile, recalled from the Connection Name dropdown (the address book lives at %AppData%\Roaming\SEL\AcSELerator\QuickSet\AddressBook.txt). QuickSet talks to one connected device at a time.
  • Passwords in the profile: the connection dialog carries the Access Level 1 and 2 passwords; QuickSet presents them as it escalates. Reads work at Level 1; the SET machinery behind a send needs Level 2.
  • Sanity check: open Communications > Terminal (Ctrl+T), press Enter for a prompt, issue ID — the reply carries the FID, boot FID, and PARTNO. Record the Z-number. Communications > Logging > Terminal Logging records the terminal session to a text file; the Connection Log keeps a log of the whole QuickSet session (all connections) until cleared.

3The settings round-trip

The workflow that everything else hangs off. Settings transfer as files, not one setting at a time — which is why version matching (§5) matters.

1 · ReadFile > Read pulls the device's settings into a new Settings Editor record (Transfer Status window)
→
2 · Edit offlinesettings tree, range + interdependency checks, Expression Builder for SELOGIC
→
3 · SaveFile > Save stores the record in the active .rdb database
→
4 · CompareEdit > Compare diffs old vs. new and produces a settings change report
→
5 · SendFile > Send transfers checked settings classes; relay disables briefly while enabling them

One full round-trip: read into the database, edits accumulate offline, the compare flags three diffs, the send pauses at the active-group gate, and the relay disables for up to 5 s (ENABLED out, ALARM pulses) while it enables the new settings. ▶ Animated in the HTML edition.

Partial vs. full sends (and reads)

The File > Send dialog lists the settings classes as checkboxes — you send what you check (Group 1, Logic 1, Global, Port F, DNP maps…), and the Transfer Status window counts the files across (e.g. "6 of 11"). Two IM fine points: QuickSet auto-selects any class where changes have been made, even if you didn't check it — deselect deliberately if you mean to hold a change back; and for a clean transfer the target port's auto-messages should be off (AUTO := N). A change window that only touches Group 2 logic need only send Group 2 files. Under a design template, the template designer controls which groups get sent (§7).

Partial reads exist too (Tools > Options > Settings > Specify groups on settings read) — but any class you don't read is filled with default settings in the resulting editor. A partial read is not a partial picture of the relay; save one over your database record and the unread classes silently revert to defaults.

The compare window

Edit > Compare diffs the open settings against a saved file: a settings tree, side-by-side Current (active editor) vs Other (comparison file) values and comments, and a filtered report. Six filters classify every setting — Changed / Unchanged / Missing (exists in only one file), each with Hidden / Invalid / Designer subsets — with counts per category ("Changed: 39/41" = 2 more hidden). View > Ignore Comments matters when comparing against settings read from a device: the relay doesn't store QuickSet comments, so without it every commented setting shows as a diff. File > Save Report exports the comparison as HTML. Enable Prompt for action on settings read (Tools > Options > Settings) and every read offers Compare / Merge / Open — the as-found-vs-as-left check in one step. Edit > Merge is the sibling: selectively pull settings from a saved file (e.g. a company-standard scheme) into the open editor via the same comparison view.

What interrupts protection (SEL-751A, as documented)

  • Saving new settings: relay disabled up to 5 s while it stores and enables them — ALARM bit sets momentarily, ENABLED LED extinguishes.
  • Active-group change: disabled <1 s; elements, timers and logic reset, but local/remote/latch bit states are retained and output contacts hold until the new group's logic is processed.
  • Editing a non-active group: no interruption — unless the change alters SS1–SS3 and triggers a group switch.
  • Side effects: an active-group settings change drives the reclosing relay to last shot and reloads the reset timer (79RSLD). Plan sends around reclose state.
  • Lockout windows: SET is unavailable up to 90 s after power-up and 40 s after a settings change; after a PORT 1 (Ethernet) or Logic change, a further change may need up to 2 minutes.

4The relay-side structure QuickSet exposes

QuickSet's settings tree mirrors the relay's settings classes. The SEL-751A stores eight classes in nonvolatile memory; the same classes are reachable by ASCII SET/SHO (Level 2 / Level 1) and, for Global/Group/Port, from the front panel:

ClassInstancesASCIIContents
Relay Groupn = 1, 2, 3SET nProtection elements, timers — per group
Logic Groupn = 1, 2, 3SET L nSELOGIC control equations — per group
Global1SET GConfiguration, group selection (SS1–SS3, TGR), input debounce, Event Messenger
Portp = F, 1 (Eth), 2, 3, 4SET P pPer-port comms parameters and protocol

DNP31SET DDNP3 map settings

Groups: each of the three settings groups is a complete set of relay + logic settings; only one is active. The active group is selected by SELOGIC settings SS1–SS3 (which win when asserted) or the GROUP n command, qualified by TGR (0–400 s, default 3), indicated by Relay Word bits SGn, and retained through power loss. In QuickSet the tree stays constant while settings for absent hardware or disabled functions dim.

Editing aids: right-click a setting for Previous Value / Default Value; out-of-range entries list as errors at the bottom (double-click to jump there); the ellipsis beside a SELOGIC setting opens the Expression Builder (enable the function under Logic Settings > SELOGIC Enable first). Tools > Settings > Import/Export round-trips settings to a small text file.

5Drivers, FID, and moving settings between relays

Every send is a file-for-file match against what the relay expects. Two identifiers must agree with the target, both visible in the ID reply:

  • Part number (PARTNO) — the hardware option string the settings file was built for.
  • Z-number — from the FID (e.g. SEL-751A-R100-V0-Z001001-…); its first three digits are the settings driver version, shown in the Settings Editor's lower-left corner. Editor driver and relay FID must match.

Replacing a relay with a newer vintage (AG2007-04's SEL-351S case: Z006 file, Z007 relay)? Salvage the old file in two moves, keeping the original via Save As:

1 · Edit > Part Numberconvert the file's part number to the new relay's; Save As under a new name
→
2 · Tools > Settings > Convertconvert the file's Z-number to the new driver version
→
3 · Review the reportthe Convert Settings report lists missed, changed, and invalid settings — read it before trusting the file
→
4 · Sendnow the file matches; transfer proceeds
If the file doesn't match, the send fails — QuickSet displays an error and transfers nothing. That's the safe direction; the dangerous direction is a conversion whose report you didn't read. In the convert report the newly converted settings sit in the Current column; the pre-conversion values in the other. Convert can even cross product families — with proportionally more of the report demanding attention.

Drivers install through SEL Compass (Install Devices button; SEL recommends closing QuickSet while installing). Don't know the Z-number yet? Create the file with the largest Z offered and convert once ID tells you. No driver available at all? The universal driver opens the file in the legacy grid editor — no rules checking, the relay simply rejects anything invalid.

6The settings database (.rdb)

QuickSet stores every device's settings as records in an .rdb database file (default Relay.rdb, shipped with example settings). Each unique relay gets its own record; kept current, the database is the record of truth for the fleet.

  • File > Database Manager creates databases and manages records: per-database and per-device description fields (protection scheme, comms particulars — use them), Rename/Copy/Delete on device settings, Import/Export to text, and a Copy/Move Settings Between Settings Databases tab with side-by-side A/B databases (arrows copy or move a device between them). An Optimize button reclaims space left by deleted/modified settings when an .rdb balloons.
  • Organize deliberately: SEL suggests multiple databases grouping similar protection schemes or geographic areas — one .rdb per substation or per standard is the usual shape. Performance guidance: keep it under ~500 settings files per .rdb, and on a local drive (network shares risk save conflicts and latency corruption — QuickSet shows a warning symbol in the save dialog).
  • Automatic backups: every save rotates a backup into an _rdb_backups folder beside the .rdb — default last 3 generations, named .01 (newest) upward, adjustable under Tools > Options > Main > Database Backup. Restore = rename the extension back to .rdb. Off-machine backup is still yours to arrange. Default location on install: %AppData%\Roaming\SEL\AcSELerator\QuickSet\Relay.RDB (AG2013-20 also lists ...\Program Files (x86)\SEL\AcSELerator\QuickSet\bin) — or just search for *.rdb.

Clean install / migration (AG2013-08, AG2013-20)

When QuickSet locks up, fails to update through SEL Compass, or misbehaves, the documented fix is a clean reinstall: back up all .rdb files first (uninstall leaves the RDB behind, but don't bet on it); back up any Device Manager database via Database Manager > AcSELerator Database tab > Backup Database (run as administrator). Then uninstall QuickSet, QuickSet Designer, SEL Commissioning Assistant, and SEL-5025 Secure Port Service; delete leftover SEL\AcSELerator folders under Program Files, AppData\Roaming, and ProgramData; reinstall from selinc.com. PC migration is the same move: carry the .rdb files, reinstall the software.

7Design Templates (AG2019-24)

Design Templates are the standardization layer: a template designer (licensed QuickSet feature) builds a locked, calculated settings front-end; template users fill in a handful of fields per feeder and everything else is derived or fixed. Per AG2019-24, templates minimize the settings visible to the person setting the relay, control what can change and what gets sent (including value ranges), and make standardized panels consistent across engineers.

  • Three views: the Settings Editor, the Design Template Editor (designer-only: equations, variables, layout), and the Design Template Preview (what the user sees). The designer can deny users the Settings Editor entirely.
  • Locking a setting: right-click → Add to Design Template turns the field green (read-only), creates a template variable, and binds the setting via an equation — visible but not editable. Add … as Constant freezes it at the current value and hides it from the user.
  • Equations use [a^b] syntax (a = group or UV for a user variable; b = the setting) and compute settings from user input — unit conversions (primary→secondary via [1^CTR]), decision logic (frequency threshold from load type), even error-check fields that glow red until the user affirms a checklist item.
  • Ranges with teeth: a panel's range validates entry (out-of-range highlights yellow), supports step sizes (0..10[.5]), and can itself be computed from settings like the CT ratio.
  • Distribution: the template is just an .rdb the designer hands out; each feeder becomes an instance filled in through the preview. Tools > Groups to Send (per settings file) controls what an unlicensed user can send — including a Designer Template settings only filter — but it binds only if Allow switching to Settings Editor from Design Template is unchecked; otherwise the user can hop to the Settings Editor and send anything. Supporting relays store the template package in the relay as SWCFG.zip, and a read from such a relay restores the template configuration itself.

The template flow: one locked standard stamps out three feeder instances; an attempted edit of a locked setting bounces (red ✕), while an allowed user field accepts the edit (teal ✓) and the equations recalculate the derived settings. ▶ Animated in the HTML edition.

8The rest of the toolbox

HMI — live metering, targets, control

  • Tools > HMI > HMI: device overview (main-board contact I/O, 16 user-assignable target LEDs), metering screens, and a Targets view of every Relay Word bit's live state.
  • The Status and SER screens mirror the ASCII STA and SER commands; the Control screen resets metering, clears Event History / SER / MB report / LDP, triggers events, resets targets, syncs IRIG, sets time/date, and operates remote bits.

Event retrieval

  • Tools > Events > Get Event Files lists the relay's history; pick 4 samples/cycle filtered (default) or 16 s/c raw under Options, then Get Selected Event. View Combined Event Files overlays up to three. Waveform anatomy → Oscillography & Event Reports in atlas.
  • SER retrieval and interpretation → SER & SOE in atlas.
  • Tools > Firmware Loader upgrades relay firmware (.s19/.z19 — .z19 loads much faster); it offers to save settings and events first (take it), then loads over Xmodem — expect 15–40 minutes. Also in the Tools menu: Chart Viewer and the Motor Start Report.

Adjacent tooling: the RTAC's engineering tool is ACSELERATOR RTAC (SEL-5033); AG2017-38's Commissioning Assistant spreadsheet generates IEC 61131-3 watch/force code for point-to-point checkout — the RTAC analog of QuickSet's HMI commissioning. QuickSet's own integrated Commissioning Assistant is narrower: it commissions SEL-487E/SEL-787 transformer schemes — hunting single-contingency wiring errors (crossed phases, wrong CT tap, reversed polarity) and computing compensation matrices.

9Gotchas & troubleshooting

  • Driver/FID mismatch: send fails with an error. Check the Settings Editor's driver number (lower-left) against the first three Z-number digits from ID. Fix the part number + Tools > Settings > Convert — and read the Convert report (§5).
  • Partial read filled with defaults: classes you don't select on a group-specified read come back as default settings, not the relay's — never save a partial read over the fleet record (§3).
  • Sent to the wrong group: Group/Logic 1, 2, 3 are separate send checkboxes. Confirm which group is active (GROUP command, front panel, SGn bits) before assuming your change is live — a send to a non-active group changes nothing in service (and interrupts nothing).
  • Password lockouts: the relay prompts only three times per attempt; a changed-and-forgotten Level 2 password means no settings access — recovery is physical (the password jumper). Keep the connection profile's stored passwords in sync when you rotate them.
  • "Relay Configuration in Progress": not a fault — you're inside the 90 s post-power-up / 40 s post-change window. Wait and retry.
  • Database sprawl: every engineer with a private Relay.rdb is a fork of the truth. Use named per-substation databases, fill in the description fields, consolidate with Copy/Move — and read-and-save from the device around each change window so the record matches the relay.
  • No prompt in Terminal: port/speed/framing mismatch, or the relay port's protocol isn't SEL. Match the relay's SET P values; PORT F defaults 9600/8/N/1.
  • Connected but transfers fail (serial): flow control — SEL's rule is hardware (RTS/CTS) flow control for speeds above 9600. Sends also want the port's auto-messages off (AUTO := N).
  • Telnet transfers fail: QuickSet's Ymodem bytes read as Telnet control characters and kill the transfer — switch the File Transfer Option to Raw TCP (or FTP/SSH where supported).
  • File transfers through an RTAC: a plain port-forward isn't enough — the RTAC must provide a direct transparent connection for QuickSet file transfers to pass.
  • Settings open painfully slowly: QuickSet running in Windows compatibility mode — turn it off in the shortcut's Properties.
  • QuickSet itself misbehaving: the documented cure is the clean reinstall of §6 — back up .rdb files first.
