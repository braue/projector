Open phase and loss of source

Both use the same detector. A dead section directly below a live point is an open phase; if it starts at the source itself it is a loss of source.

§08DA Lib / DA Adapter 105.0.2Code-derived

The rules, stated plainly

  1. Detection needs the feeder and every voltage point on it to be armed: each must have seen Live1 for half the OpenPhaseConfirmTime.
  2. The detector finds the first closed device (walking out from the source) whose upstream side is live and everything downstream is dead. That condition must hold for EventDetectTime to latch, and for OpenPhaseConfirmTime to confirm.
  3. If the dead section starts before the first switching device, it is a loss of source.
  4. Any fault activity, bus-restore activity, DA analysis or execution, or a loop change blocks detection for 10 s after it clears.
  5. A loss of source only proceeds to restoration if LossOfSourceRestoreTime = 0 (automatic) or an operator sends LossOfSourceRestore inside that window.

Arming

  • Device arming (OpenPhase.Armed): AR enabled, not told to disarm, the device sees ≥ Live1, closed, no discrepancy alarm, no comm failure — for OpenPhaseConfirmTime / 2. Disarms after OpenPhaseConfirmTime + EventDetectTime of being dead or open (paused while DA is in progress), immediately on discrepancy alarm, comm failure, AR disable or a disarm message. Equipment/EQUIPMENT
  • PT arming: each sensed terminal arms the same way on its own voltage. Equipment/Measurements/Voltage/Sensor/EQUIPMENT_VOLTAGE_SENSOR
  • Feeder arming: AR enabled, feeder armed, open-phase or LOS detection enabled, no source event / tripped fault / confirmed event, no bus-restore activity if a bus is upline, AND every node-source device on the feeder armed AND every PT on those nodes armed. When the feeder is not armed it sends a disarm message to all its devices and PTs, so after any event they need the full re-arm time again. Feeder/Voltage/FEEDER_DetectOpenPhase
Interpretation One device on the feeder that has not re-armed (just closed, recently comm-failed, sitting at Indeterminate voltage) keeps open-phase detection off for the whole feeder. After any DAC operation there is a quiet period of at least OpenPhaseConfirmTime / 2 (30 s with defaults) before open-phase protection is back.

Detection

Walking the actual topology from the source, for each closed device that feeds a node: if the node above it is Live (better than Indeterminate) — or for the very first device, if a bus/transformer exists upline (or no bus object at all) — AND everything downstream of it is Dead (no node above Dead and no device with a voltage discrepancy), the timer runs. After EventDetectTime the device is latched as the open-phase point and the feeder's OpenPhase.New/Latched set. Only the first such location is taken. If open-phase detection is disabled and only LOS detection is enabled, only the first device is checked. Feeder/Voltage/FEEDER_DetectOpenPhase Shared/Voltage/checkDead

Confirmation and location

In ANALYZE, once the open phase has been latched for OpenPhaseConfirmTime (or a loss of source is already confirmed, or a remote DAC confirmed it) and no fault is present, class_OpenPhase.Confirm walks downstream. The location is a device whose entire upstream path is Live and whose node is Dead (or all of its downstream branches are dead), with no deeper location. If nothing qualifies by the end of the confirm time, the latch is dropped. Feeder/Event/OpenPhase/class_OpenPhase

  • Location at switch depth 0 (no switching device between the source and the dead section) → LossOfSource event and target.
  • Reconfiguration starts only if the location is at depth ≥ 1, or for LOS when LossOfSource.Restore is set.
  • The open-phased device and downstream non-isolating equipment are flagged OpenPhased; abnormal devices downstream are added to the abnormal check list as interrupted.
  • Unmetered switches: downstream switches that have no PT of their own but carry inferred voltage along a single metered path get InhibitControlOpenPhaseIsolation. The DAC cannot tell which side of such a switch the open conductor is on, so it will not use it as an isolation point; the zone extends past it. These appear in the event report as open-phase-inhibited switches.

The per-circuit IsolateOpenPhase pin (ENABLE/DISABLE/GLOBAL) overrides the scheme. AllowExtendedOpenPhaseRestoration (default FALSE) lets restoration paths run through open-phase-flagged equipment.

Loss of source

  • Enabled by EnableLossOfSourceDetection (Adapter default TRUE, Lib FALSE).
  • LossOfSourceRestoreTime = 0 (both defaults): restoration is automatic once confirmed.
  • > 0: the circuit's LossOfSource output asserts and LossOfSourceRestoreWindow counts down; a rising edge on the circuit's LossOfSourceRestore inside the window starts the restoration. Outside the window nothing happens. If the source comes back the LOS state resets.
  • Adapter: on circuits with IsolateBreakerZone set, a confirmed and restorable LOS is converted into a source event so that the breaker zone is isolated (§09). ADP/DA_FDR
  • No immediate isolation is done on a feeder with an open-phase or LOS event unless that feeder is set to isolate open phases.
