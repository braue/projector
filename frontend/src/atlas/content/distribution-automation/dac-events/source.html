Source events

An external "the source of this circuit is gone or untrustworthy" signal: transformer bank lockout, bus lockout, breaker failure, low-side hot-line tag, or a custom trigger.

§09DA Lib / DA Adapter 105.0.2Code-derived

The rules, stated plainly

  1. Triggered by the rising edge of the circuit's SourceEvent, accepted only if the feeder is armed and allowed to isolate (an abnormal feeder in mode None ignores it).
  2. Confirmed as soon as the feeder reaches ANALYZE (after the update poll).
  3. The first switching device of the feeder (normally the feeder breaker) is the isolation point and is opened immediately; everything behind it is restored from alternates.
  4. With IsolateBreakerZone, the breaker zone (breaker to first downstream switches) is isolated instead and left dead.
  5. A feeder with a latched source event is never used as an alternate source ("Source Faulted").

Detail

  • Confirmation walks the feeder and runs isolation at switch depth 1 with "open now" and "set recent open as root" so that a breaker which has already tripped still produces a root behind it. Feeder/Event/Source/class_SourceEvent
  • If a fault is present at the same time, the source event stands in for the lockout: the fault is confirmed and located without waiting for a relay lockout. Feeder/Event/mFEEDER_ConfirmEvent
  • With a source event, a miscoordinated locked-out device at the first level is not reclosed.
  • Abnormal devices on the feeder are added to the abnormal check list as interrupted.
