Places where the code does something surprising. Each is worth confirming on a test set before relying on it.

§24DA Lib / DA Adapter 105.0.2Code-derived
#WhereObservation
1OBJ/DA_CIRCUITPer-circuit DetectMiscoordination override actually reads the IsolateOpenPhase pin. Only matters if either is set off GLOBAL.
2fb_RestorationSourceCheckTransferDepth = 0 prevents crossing any tie in the restorability check (unless g_BypassDepthCheck), so outaged branches become non-restorable. Lib default is 0; Adapter default 2. Since 105.0.2 the flags no longer carry over into RTN.
3ADP fb_HeartbeatHeartbeat setpoint range check uses OR; any value is accepted, including 0.
4mFEEDER_FindReturnSwitchesRTN source-group mismatch is reported as CapacityLimit.
5mAR_CompareStates"Maximise load restored" and "same-feeder restoration" criteria disabled.
6mAR_FindSolutionAlways returns TRUE; the best executable state is executed even if it restores little. Partial restoration is signalled only by CapacityLimit/RestorationFail.
7OBJ/DA_MANAGER_ARClosedTransition hard-coded TRUE.
8OBJ/DA_MANAGER_AROverload and load shed silently disabled when any DA_CONNECTOR exists.
9Revision_HistoryLoad shed flagged "untested, do not enable".
10OBJ/DA_DG_CURTAILMENTMarked obsolete, "needs updates before deployment".
11OBJ/DA_MANAGER_ARReset is silently dropped while DA is in progress (not queued).
12DefaultsAdapter and Lib defaults differ on 12 settings (§20). Projects using raw Lib blocks behave differently from Adapter projects with the same visible configuration.
13prvfb_LicenseManagerDemo license: the 4-hour DemoOver timeout disables DFO only. AR stays licensed until a restart, despite the Adapter's description.
14ADP/DA_CONTROLDFO Functionality Unlicensed alarm is driven by the AR licensed flag.
15prvfb_LicenseManagerExceeding the licensed feeder count (connectors included) disables AR for the whole RTAC, not just the excess feeders.
16class_SettingsErrorsDuplicate connector ID shows as "Duplicate Instances" in SettingsErrorText (flag mapping crossed). The log entry is correct.
17ADP/DA_CONTROLScheme Include/Exclude are cross-wired when mapped as two device-definition indexes. Other mapping methods are correct.
18Global_VariablesCHECK_POLL = FALSE: no check poll after a command. Feedback timing depends entirely on the RTAC's normal communication.
19OBJ/DA_CONNECTORA feeder is reported excluded to the connector partner only if it is also abnormal. An excluded or UF-excluded feeder in normal condition looks available to the partner. §17
