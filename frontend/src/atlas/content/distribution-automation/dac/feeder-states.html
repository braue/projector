DAC — Feeder States, Arming & Reset

The three feeder states, what arms a feeder, what Reset clears, and what non-normal configuration affects

3 statesEnable + not ExcludeReset ≠ abortnon-normal

☰Core facts

  • Armed = scheme Enabled AND feeder not Excluded. All feeders are included by default.
  • Only an armed feeder detects events. An unarmed feeder is also unavailable as an alternate source.
  • Reset is a target reset, not an abort. It clears latched indications and forces a poll.
  • Reset is ignored while any event is being operated on anywhere in the system.
  • The only way to abort an event in progress is to disable the DAC.
  • Non-normal configuration affects return to normal only. It does not alter the response to any event.

1The three states

Every feeder is in one of three states at all times.

Feeder state machine. Reset from Armed is honoured only when no AR sequence is in progress. ▶ Animated in the HTML edition: startup, arming, and both ways back out.

Initialize

Entered: at controller power-up, or on a scheme Reset issued while all feeders in the scheme are idle.

Does: resets internal variables and alarm conditions; evaluates the configuration of the distribution system to determine the normal operating arrangement.

Exits to: Unarmed, once initialized.

Unarmed

Entered: after initialization; on an Exclude command; when the scheme is disabled.

Does: monitors the scheme state.

Exits to: Armed when the scheme is enabled and the feeder is not excluded. Initialize on a Reset command.

Armed

Entered: when the operator enables the system and the feeder is not excluded.

Does: monitors for an undervoltage, fault, or overload indication from any recloser control, switch control, feeder relay or other IED on the feeder. An indication starts the event sequence.

Exits to: Unarmed if the scheme is disabled or the feeder excluded. Initialize on a Reset with no AR sequence in progress.

2Arming and exclusion

Scheme enable/disable is one operator control. Feeder include/exclude is one control per feeder. Both are SCADA points — DAC_EnableDisableCommand, Feeder_<Bkr>_ExcludeIncludeCommand.

Excluding a feeder does two things. It stops the DAC acting on events on that feeder, and it removes the feeder as an alternate source for its neighbours. Exclusion is listed as a disqualifier for restoration.

An abnormal feeder is disqualified the same way — see Abnormal Conditions.

3Reset

Reset controls are SCADA points modeled on a relay's Target Reset. One per feeder, plus one system-wide.

System ResetFeeder Reset
Resets system-level event indicators — Permanent Fault Event, Event Failed due to Abnormal Status, and similar —
Resets feeder-level event indicators for all feeders — Feeder operated due to Permanent Fault, Feeder Reconfigured, and similar Resets feeder-level event indicators
Resets Command Failure and Close-onto-Fault statuses and Opened to Isolate Open Phase targets on all devices Resets the same three, only on devices within the normal extent of the feeder
Triggers an update poll of every device in the system Triggers an update poll of devices within the normal extent of the feeder
Feeder Reset does not reach devices beyond the feeder's normal tie points. After a restoration the feeder is extended past those ties, so the devices that just operated are not reset. Use the system Reset, or reset the feeder that normally owns them.
Command Failure and Close-onto-Fault clear only by a scheme or feeder Reset. Both latch. Neither clears when the field condition clears.

Reset is ignored if an event is currently being operated on anywhere in the system. To stop a sequence in flight, disable the DAC.

4Non-normal configuration

Every switching device is designated NC or NO at setup. A feeder is in a non-normal configuration if the present state of any device on it differs from its designated normal state. One NC recloser open, or one NO tie closed, is sufficient.

A feeder is also non-normal if the configured normal states produce a loop between radial sources — no NO point separating two sources. Deliberate loops must be configured as loop objects; see System-Level Optional Features.

Non-normal configuration is used only for return to normal. It does not gate, delay or alter automatic reconfiguration. A non-normal feeder answers events from present topology.

5What survives a restart

By default every SCADA-controlled status resets to its default when the RTAC restarts, reboots, or has a new settings file applied. The Setpoint Retention setting (DAC Extension → Settings tab) carries across:

  • Per-device Out of Service, Bypass, Inhibit
  • Per-feeder Exclude
System Enabled is never retained, with or without the setting. After any restart the scheme must be enabled by a SCADA control.
