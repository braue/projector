1Advanced system options — Structured Text

Syntax: Scheme.VoltageDeadband := 3;

ParameterTypeDefaultWhat it gates
IntegrityPeriodTIME300 sTime between integrity polls of connected end devices. Also the window for the "offline for an entire integrity period" comms-failure test.
VoltageDeadbandLREAL2Voltage hysteresis band, as a % of nominal, for transitions between voltage levels.
UpdateTimeLimitTIME120 sMaximum time in the Update step before advancing. Also declares command failures during closed-transition operations.
AnalyzeTimeLimitTIME120 sMaximum time in the Analyze step before a sequence failure. The maximum time to confirm an event. Must be greater than OpenPhaseConfirmTime or open-phase detection cannot work.
ReconfigTimeLimit
OM calls it ReconfigurationTimeLimit		TIME120 sMaximum time in the Reconfiguration step before a sequence failure is declared.
EventDetectTimeTIME10 sHow long an open-phase or overload condition must be present before the event sequence starts.
OpenPhaseConfirmTimeTIME60 sDelay when confirming a broken jumper or dead-bus condition. Allows voltage to be restored by external means. Half this value is the healthy-voltage window required before open-phase detection is permitted.
LoopConfirmTimeTIME60 sHow long two feeders may be operated in parallel before a Loop alarm is declared.
MinimumUpdateTimeTIME10 sMinimum time in the Update step. For devices that go straight to lockout — high-set overcurrent, underground systems — so field readings settle.
EnableLossOfSourceDetectionBOOLTRUEEnables loss-of-source detection. Ignored if open-phase detection is enabled, which enables LOS automatically.
EnableVoltageDiscrepancyBOOLFALSEEnables voltage discrepancy detection. Off by default; see Abnormal Conditions for what off costs.
CloseDelayTIME0 sDelay between a close command being queued and sent. Set non-zero on high-speed comms where isolation steps report opened before the mechanism finishes moving.
BlockCloseModeenumBlockCloseDisabledBlockCloseDisabled · AllClosedTransition · DifferentSourceGroups. See System-Level Optional Features.
SettingsVersionREAL1.0Version tracker for system settings. A mismatch between primary and backup disables automatic failover in a redundant pair.

Two timers referenced by the OM do not appear in this table: OverloadConfirmTime1 / OverloadConfirmTime2 (extension: Overload Detection Time 1/2) and ShedTime.

2DAC Extension — Settings tab

SettingEffect

Dead Voltage PercentMaximum % of nominal for a line to count as fully de-energized. Typically ~20%, to accommodate PT noise on a dead line.

3Per-device settings that change behavior

SettingApplies toEffect
Normal Statusall switching devicesNC or NO. Defines the normal topology used for RTN. Minor influence on preferred switching orders.
Capacity (A)allLevel 1 overload threshold. Constant or REAL variable for seasonal ratings. Must be ≤ Temporary Capacity.
Temporary Capacity (A)allLevel 2 threshold. The ceiling the DAC will load the device to after a non-overload event.
Source GroupbreakersPositive integer. Matching groups transfer closed-transition; non-matching transfer open-transition. If the substation is modeled the value is inherited from the active transformer, but this setting must still hold the normal source group.
Lockout Period (s)virtual breakersHow long the area downstream must be de-energized before the device counts as locked out. Estimates when reclosing finished. Ignored on physical breakers.
Lockout ModereclosersGang Lockout · Single-Phase Lockout · Dynamic. Dynamic additionally requires the Dynamic Single-Phase Lockout Mode data point mapped.
SG1–SG6 Sourcesreclosers, breakersBreaker device names, comma-and-space separated for multiple sources per group. Max six sources across all entries per device. Blank = no change required from that source.
Load Break CapableswitchesFalse = the DAC opens it only when it is de-energized from both sides. Reclosers are always capable.
Source/Load Side PT Location, PT 1/PT 2 LocationallWhich template voltages to read per side. Choose None where no valid three-phase PT set exists. Incomplete PT coverage merges zones for open-phase detection.
Bus ID / NodeallBuilds the electrical topology. Shared node names link devices electrically. No spaces, commas, hyphens, periods or semicolons.
Data Source / Shared Data SourceallThe DNP client session, and whether it is a concentrator. Shared sources prepend Device_<Name>_ to expected tag names, except breaker bus voltages, which keep the bare template tag name because they are shared between devices.
[Virtual] as Data SourcebreakersMarks a breaker the DAC cannot communicate with. Statuses are inferred.

4Constraints between settings

AnalyzeTimeLimit > OpenPhaseConfirmTimeOtherwise Analyze times out before an open phase can be confirmed. Defaults satisfy this (120 s vs 60 s).
ShedTime > OverloadConfirmTime2Otherwise the DAC sheds before attempting a load transfer, and operators get no warning window.
Capacity ≤ Temporary CapacityPer device. Level 1 must be the lower threshold.
Live Level 1 ≤ Live Level 2Set equal to disable sag monitoring.
Load shed requires transferLoad shed may be enabled only if overload load transfer is enabled.
Open phase implies LOSEnabling open-phase detection enables loss-of-source detection and makes EnableLossOfSourceDetection irrelevant.

5Which timer bites, and when

SymptomTimer to look at
Open-phase events never confirmAnalyzeTimeLimit vs OpenPhaseConfirmTime.
Sequences run ~10 s longer than expected on fast tripsMinimumUpdateTime. Expected.
Update times out on a device that is aliveUpdateTimeLimit, and the IntegrityPeriod that feeds the offline test.
Closed-transition Opens declared failed too earlyUpdateTimeLimit. It declares command failure here, not the reconfiguration limit.
Closes sent before mechanisms have finished openingCloseDelay.
Reconfiguration aborts part-wayReconfigTimeLimit, then the abnormal, command-failure and voltage alarms.
Overload acted on areas only briefly overloadedThe overload timers are system-wide. Expected behavior. See Overload.
