The data model

Every device block, line and load becomes one or more entries in dEQUIPMENT[1..2000], each with two terminals that point at connectivity nodes in dNODE[1..2000]. Device FBs are chained with A/B node indexes exactly as drawn in the area diagram. A switching device FB actually creates three equipment entries: a virtual A-side line, the switch itself, and a B-side line that carries the section's LoadAllocation, R and X. OBJ/DA_RECLOSER_AV_BV

A DA_CIRCUIT creates a SOURCE equipment and a FEEDER instance. The feeder's actual topology is rebuilt by walking from that source through closed equipment; its normal topology by walking through normally-closed equipment. Every node records which feeder, source, source group and source-side equipment feed it (dNODE.Actual and .Normal).

What runs each scan, in order

  1. Adapter DA_CONTROL.prv_Run: read SCADA controls and heartbeat, run redundancy, then feeder-group controllers and DAC-interconnect managers.
  2. DA_CONTROLLER: licence check (AR and DFO feeder counts), startup pulse (first 3 scans), controller-reset pulse, scan-time estimate, node voltage update, equipment and node margins, node overloads, the integrity poll, customer-count and post-outage managers, event recorder. OBJ/DA_CONTROLLER
  3. DA_SCHEME: converts the voltage percentages into primary and secondary thresholds; publishes settings-error outputs.
  4. DA_MANAGER_AR: scheme-wide enable, aggregation of feeder states, solve, execute, timers, collaboration state machine. OBJ/DA_MANAGER_AR
  5. Device blocks (in diagram order): each EQUIPMENT maps inputs, detects abnormal/continuity/close-on-fault, runs its fault detector, voltage sensor, comm monitor and commands. Each DA_CIRCUIT runs its FEEDER state machine.
Interpretation Because devices and feeders run after the manager, a flag set by a feeder in scan N is acted on by the manager in scan N+1. Many "pulse" flags in the code are held for a cycle for exactly this reason (for example Update.Request is cleared only after it has been present one full cycle).
