# SEL Product Family Map

SEL model numbers are opaque until you've met the family. This page maps every product that
appears in the reference library to what it actually does — the "what is a SEL-XXXX again?"
lookup. Descriptions come from each product's data sheet or instruction manual, so a row here
means the document exists in the library.
