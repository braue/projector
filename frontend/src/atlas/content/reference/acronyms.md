# Acronym & Term Glossary

One line each. Where a term deserves a page, the page is linked.

## A

| Term | Meaning |
|---|---|
| **AC** | Alternating current |
| **ACSELERATOR** | SEL's family of engineering software (QuickSet SEL-5030, RTAC SEL-5033, TEAM SEL-5045, …) — see [SEL Software Map](atlas:reference/sel-software-map.md) |
| **A/D** | Analog-to-digital converter — the relay's front end |
| **AFD** | Arc-flash detection — light plus current — see [Arc-Flash Detection](atlas:protection/arc-flash-detection.html) |
| **AI / AO** | Analog input / analog output (protocol point types) |
| **ANSI** | American National Standards Institute; colloquially, the C37.2 device numbers |
| **AOUTSLOT** | SEL setting listing outputs processed on the fast (1/16-cycle) interval |
| **APN** | Access point name — the carrier-side network a cellular device attaches to |
| **AR** | Automatic reconfiguration (a DAC/FLISR function) |
| **as-built** | Drawings updated to match what was actually installed |
| **as-found / as-left** | Device settings read before and after a visit |
| **autosynchronizer** | Logic that drives governor and exciter to bring a machine into synchronism, then closes |

## B

| Term | Meaning |
|---|---|
| **BCD** | Binary-coded decimal; also, on the SEL-411L, broken-conductor detection |
| **BFI** | Breaker failure initiate — see [Breaker Failure](atlas:protection/breaker-failure.html) |
| **BI / BO** | Binary input / binary output (protocol point types) |
| **BIL** | Basic insulation level |
| **Blueframe** | SEL's container-based application platform — see [Substation Computers & Blueframe](atlas:rtac-automation/sel-computers.html) |
| **Buchholz** | Gas accumulation relay on conservator-type transformers |
| **burden** | The load a CT or PT secondary circuit presents, in ohms or VA |
| **bus** | A common connection point; also a communications bus |

## C

| Term | Meaning |
|---|---|
| **CBCT** | Core-balance current transformer — a window CT for sensitive ground detection |
| **CCVT** | Coupling capacitor voltage transformer |
| **CID** | Configured IED description (IEC 61850 SCL file) |
| **COMTRADE** | IEEE C37.111 common format for transient data exchange — event files |
| **CROB** | Control Relay Output Block (DNP3 Group 12 Variation 1) — see [DNP3 Control Models](atlas:data-protocols/dnp3/controls.html) |
| **CT** | Current transformer — see [CT & PT Fundamentals](atlas:fundamentals/ct-pt-fundamentals.html) |
| **CTI** | Coordination time interval — the margin between two coordinating curves |
| **CTR** | CT ratio setting in an SEL relay |

## D

| Term | Meaning |
|---|---|
| **DAC** | Distribution Automation Controller — see [how the DAC decides](atlas:distribution-automation/dac/how-it-decides.html) |
| **DAN / SAN** | Dual- / single-attached node (IEC 62439-3, PRP/HSR) |
| **DC** | Direct current; in a substation, the station battery system |
| **DCB** | Directional comparison blocking (pilot scheme) |
| **DCUB** | Directional comparison unblocking (pilot scheme) |
| **DER** | Distributed energy resource — see [DER Interconnection](atlas:distribution-equipment/der-interconnection.html) |
| **DETC** | De-energized tap changer — moved only with the transformer out of service |
| **DFR** | Digital fault recorder |
| **DG** | Distributed generation |
| **DGA** | Dissolved gas analysis (transformer oil) |
| **DMA** | Device Management and Automation (a Blueframe application area) |
| **DNP3** | Distributed Network Protocol, IEEE 1815 — see [DNP3 Fundamentals](atlas:data-protocols/dnp3/fundamentals.html) |
| **DTT** | Direct transfer trip |
| **duty cycle** | The defined load-versus-time sequence a battery must support |

## E

| Term | Meaning |
|---|---|
| **effectively grounded** | X<sub>0</sub>/X<sub>1</sub> ≤ 3 and R<sub>0</sub>/X<sub>1</sub> ≤ 1 — bounds healthy-phase overvoltage |
| **EFD** | External fault detection (differential security logic) |
| **EIA-232 / -485 / -422** | Serial electrical interface standards — see [Serial Comms](atlas:comms/serial-comms.html) |
| **end zone / dead zone** | The region between a CT and its breaker, outside the differential zone |
| **EtherCAT** | The deterministic fieldbus used by Axion remote I/O |
| **equalize** | An elevated charger voltage that rebalances weak flooded cells |

## F

| Term | Meaning |
|---|---|
| **FAT / SAT** | Factory / site acceptance test — see FAT & SAT |
| **FCI** | Faulted-circuit indicator |
| **FHSS** | Frequency-hopping spread spectrum (radio) |
| **FID** | Firmware identification string — decides which settings and Relay Word bits exist |
| **FLA** | Full-load amperes (motor nameplate) |
| **FLISR** | Fault location, isolation, and service restoration |
| **Fresnel zone** | The ellipsoid around a radio path that must stay clear of obstructions |

## G

| Term | Meaning |
|---|---|
| **GNSS** | Global navigation satellite system — the clock's time source |
| **GOOSE** | Generic Object Oriented Substation Event (IEC 61850) — see [IEC 61850 & GOOSE](atlas:data-protocols/iec61850-goose.html) |
| **GPR** | Ground potential rise |
| **GSU** | Generator step-up transformer |

## H

| Term | Meaning |
|---|---|
| **HRG** | High-resistance grounded — see [System Grounding](atlas:fundamentals/grounding-systems.html) |
| **HSR** | High-availability Seamless Redundancy (ring, IEC 62439-3) |
| **HMI** | Human-machine interface |
| **holdover** | A clock's behavior after losing its time source |

## I

| Term | Meaning |
|---|---|
| **ICD** | IED capability description (IEC 61850 SCL file) |
| **IED** | Intelligent electronic device — any microprocessor relay, meter, or controller |
| **IIN** | Internal indications (DNP3 outstation status bits) |
| **incident energy** | Energy delivered to a surface at a working distance during an arc flash |
| **inrush** | The transient magnetizing current when a transformer is energized |
| **IRIG-B** | Inter-Range Instrumentation Group time code B — see [Time Synchronization](atlas:comms/time-sync.html) |
| **ISM band** | License-free radio spectrum (900 MHz in North America) |

## L

| Term | Meaning |
|---|---|
| **LDC** | Line-drop compensation (voltage regulator control) |
| **LEA** | Low-energy analog — low-voltage sensor inputs on newer SEL relays |
| **LO** | Lockout |
| **LOP** | Loss of potential — a blown VT fuse, and the logic that detects it |
| **LOTO** | Lockout / tagout |
| **LPCT** | Low-power current transformer |
| **LTC** | Load tap changer — operates on load, unlike a DETC |

## M

| Term | Meaning |
|---|---|
| **MBAP** | Modbus application protocol header (Modbus TCP) |
| **Mirrored Bits** | SEL's relay-to-relay bit transfer — see [Mirrored Bits](atlas:data-protocols/mirrored-bits.html) |
| **MMS** | Manufacturing Message Specification (IEC 61850 client/server) |
| **Modbus** | Register-and-coil protocol — see [Modbus Fundamentals](atlas:data-protocols/modbus/fundamentals.html) |
| **MOT** | Model option table — the part-number structure defining what a device physically has |
| **MTBF** | Mean time between failures |
| **multimode / single-mode** | Fiber types — short reach versus long reach |

## N

| Term | Meaning |
|---|---|
| **NC / NO** | Normally closed / normally open |
| **NERC CIP** | North American reliability standards for cyber assets — see [Substation Cybersecurity](atlas:comms/cybersecurity.html) |
| **NGR** | Neutral grounding resistor |
| **NTP / SNTP** | Network Time Protocol / Simple NTP |

## O

| Term | Meaning |
|---|---|
| **ONAN / ONAF** | Oil natural air natural / oil natural air forced (transformer cooling classes) |
| **oscillography** | The relay's captured waveform record |
| **outstation** | The device a SCADA master polls (DNP3 terminology) |

## P

| Term | Meaning |
|---|---|
| **PDC** | Phasor data concentrator |
| **per-unit (pu)** | A normalized unit system — see [Formulas](atlas:reference/formulas.md) |
| **PHROT** | SEL setting for system phase rotation (ABC or ACB) |
| **PMU** | Phasor measurement unit |
| **point-on-wave** | Switching timed to a specific point in the voltage or current wave |
| **POTT / PUTT** | Permissive overreaching / underreaching transfer trip (pilot schemes) |
| **PPE** | Personal protective equipment |
| **PRP** | Parallel Redundancy Protocol (dual LAN, IEC 62439-3) — see [PRP & HSR](atlas:comms/prp-hsr-redundancy.html) |
| **PT / VT** | Potential (voltage) transformer |
| **PTP** | Precision Time Protocol, IEEE 1588 |
| **PTR** | PT ratio setting in an SEL relay |

## Q

| Term | Meaning |
|---|---|
| **quality (q)** | The validity attribute carried alongside a value — see [RTAC Tags & Quality](atlas:rtac-automation/rtac-tags.html) |
| **QuickSet** | ACSELERATOR QuickSet SEL-5030, the relay settings tool |

## R

| Term | Meaning |
|---|---|
| **RedBox** | Redundancy box — attaches single-attached nodes to a PRP or HSR network |
| **REF** | Restricted earth fault — sensitive ground protection for a grounded-wye winding |
| **Relay Word** | The named boolean state bits inside an SEL relay — see [Inside a Protective Relay](atlas:relays-devices/relay-anatomy.html) |
| **ROCOF** | Rate of change of frequency (81R) |
| **Rogowski coil** | An air-core current sensor with no iron to saturate |
| **RSTP** | Rapid Spanning Tree Protocol — see [RSTP & Topologies](atlas:comms/rstp-topologies.html) |
| **RTAC** | Real-Time Automation Controller (SEL-3505/3530/3532/3555/3560) — see [RTAC Platform](atlas:rtac-automation/rtac-platform.html) |
| **RTD** | Resistance temperature detector |
| **RTN** | Return to normal |
| **RTU** | Remote terminal unit |

## S

| Term | Meaning |
|---|---|
| **SBO** | Select-before-operate (a two-step control model) |
| **SCADA** | Supervisory control and data acquisition |
| **SCD** | Substation configuration description (IEC 61850 SCL file) |
| **SCL** | Substation Configuration Language (IEC 61850 file family) |
| **SELogic** | SEL's relay control-equation language — see [SELogic](atlas:relays-devices/selogic.html) |
| **SER** | Sequential Events Recorder — the relay's own bit-change log — see [SER & SOE](atlas:relays-devices/ser-soe.html) |
| **SFP** | Small form-factor pluggable optical transceiver — see [Fiber & SFPs](atlas:comms/fiber-sfps.html) |
| **SDN** | Software-defined networking (SEL-2740S / SEL-5056) — see [SDN](atlas:comms/sdn.html) |
| **SLG** | Single line-to-ground fault |
| **slip** | The frequency difference between two sources being synchronized |
| **SOE** | Sequence of events — the system-level assembled log |
| **stub bus** | The short section between two breakers when the line disconnect is open |
| **SV** | Sampled Values (IEC 61850-9-2) |

## T

| Term | Meaning |
|---|---|
| **TCC** | Time–current characteristic (the coordination curve plot) — see [Coordination & TCC](atlas:protection/coordination-tcc.html) |
| **%TCU** | Percent thermal capacity used (motor thermal model) — see [Motor Protection](atlas:protection/motor-protection.html) |
| **TiDL** | SEL's digital secondary system using point-to-point fiber to merging units |
| **TOL** | Time-overlight — the inverse light element in arc-flash detection |
| **TSOK / IRIGOK** | SEL Relay Word bits indicating a valid time source |
| **turns ratio** | The transformer or instrument-transformer winding ratio |

## U

| Term | Meaning |
|---|---|
| **UFLS** | Underfrequency load shedding — see [Frequency & Load Shedding](atlas:protection/frequency-load-shedding.html) |
| **unsolicited** | An outstation reporting an event without being polled |

## V

| Term | Meaning |
|---|---|
| **V/Hz** | Volts per hertz — the overexcitation quantity (device 24) |
| **VFD** | Variable-frequency drive |
| **VLA / VRLA** | Vented (flooded) / valve-regulated lead-acid battery |
| **VLAN** | Virtual LAN, IEEE 802.1Q — see [VLANs](atlas:comms/vlans.html) |
| **vector group** | The transformer connection and phase-shift notation (Dyn1, YNd11, …) |
| **vector shift** | An islanding-detection method based on a step in voltage phase angle |

## W

| Term | Meaning |
|---|---|
| **wetting voltage** | The DC supplied through a field contact to operate a relay input |
| **window CT** | A CT encircling all three conductors, measuring true residual current |

## Z

| Term | Meaning |
|---|---|
| **zig-zag** | An interconnected-wye grounding transformer that creates a neutral on a delta system |
| **zone** | A protected region bounded by CTs; adjacent zones must overlap |
| **3I<sub>0</sub> / 3I<sub>2</sub>** | Three times the zero- and negative-sequence current — the quantities relays actually publish |
