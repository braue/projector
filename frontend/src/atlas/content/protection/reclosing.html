Reclosing (79) & Recloser Controls

The automatic reclosing state machine in depth — shots, open intervals, reclaim timing, lockout, sequence coordination — and the recloser control as a device class: fast/delayed curves, hot line tag, batteries, single-phase tripping

☰The rules, stated plainly

Reclosing

  • The 79 is a three-state machine: Reset (ready), Reclose Cycle (working through shots), Lockout (no closing until a human/SCADA closes the breaker and the reset timer finishes). Auto-reclosing happens only in Reclose Cycle.
  • Each shot is one open interval then one automatic close. The shot counter increments when the open interval times out — just before the reclose.
  • The reset (reclaim) timer is the "did the reclose stick?" test: the breaker must stay closed for the reset time before the sequence rearms and the counter clears.
  • A recloser control is a feeder relay plus everything the pole-top device needs: trip/close energy (capacitors + battery), operator controls (hot line tag, reclose enable), curve sequencing (fast, then delayed).
  • Fuse saving is the point of fast/delayed curves: trip fast below the fuse for the first shot(s) so a temporary fault clears, then switch to the delayed curve so a permanent lateral fault blows its fuse instead of locking out the feeder.

1Why reclose at all

Most distribution faults are temporary — a branch across two phases, an animal, a lightning flashover. Open the circuit long enough for the arc to extinguish and the cause to fall away, close back in, and service is restored in seconds with no truck roll. Reclosing automates exactly that: trip, wait an open interval, close, repeat up to a set number of shots. Only a genuinely permanent fault exhausts the sequence and drives lockout — the signal that a human (or automation) is now needed. The design rests on one asymmetry: reclosing into a still-faulted line costs one more fault-duty operation; not reclosing after a temporary fault costs an outage.

Bigger picture: the DAC (atlas → Distribution Automation → DAC) does nothing while a 79 sequence runs — reclosing gets its chance first; only a recloser lockout starts the isolate-and-restore logic. Change shot counts or open intervals and you change how long the DAC waits.

Reset ("reclaim") timing — two timers, not one

  • 79RSD (default 15 s) qualifies closures in the Reclose Cycle state — did the automatic reclose hold? Also the reset time used by sequence coordination (§5).
  • 79RSLD (default 5 s) qualifies closures from Lockout — usually manual/SCADA closes — and is the reset time at power-up and after settings changes. Typically shorter than 79RSD, emulating motor-driven-timer reclosers that reset quickly from the lockout position. Independent settings; monitor with RSTMN and OPTMN.
  • 79BRS (block reset timing, factory := TRIP) freezes the reset timer; on release the timer reloads fully — reset timing must be continuous. 79BRS := (51P1P OR 51G1P) AND 79CY stops the sequence rearming while overcurrent is still picked up mid-cycle ("repetitive trip-reclose cycling"), while AND 79CY deliberately lets cold-load inrush after a close from lockout pass.

  • Last shot = the number of open intervals before the first one set to zero. 79OI1 := 0.5, 79OI2 := 10, 79OI3 := 0 → two reclosures. If a preceding interval is zero, later nonzero ones are dead; 79OI1 := 0 defeats the reclosing relay.
  • Shot counter: at shot = 0 the relay times on 79OI1; each timeout increments the shot (bits SH0–SH4, one asserted at a time) and loads the next interval. It can't pass last shot for auto-reclosing, resets to 0 on return to Reset, and is visible live with the TARGET command.
  • Initiation: 79RI is rising-edge detected; 79RIS must already be true at that edge or the relay goes straight to Lockout. The factory pair (TRIP / 52A OR 79CY) requires the breaker closed for the first trip only — on later instantaneous trips the slow 52a indication hasn't caught up yet, so 79CY stands in. Alternative: initiate on breaker opening, 79RI := NOT 52A, 79RIS := TRIP (needs TDURD long enough that TRIP is still up at the opening; an external opening with TRIP down then correctly locks out).
  • Skip shot (79SKP): if true at initiation, the shot counter jumps ahead and the next open interval is used. Manual example: 79SKP := 50P2P AND SH0 — a high-magnitude fault skips the short first interval. AG9903 uses the same mechanism to pick a 45-cycle vs 2-second first reclose from a panel switch.
  • Stall (79STL): open-interval timing pauses while asserted and resumes where it left off. Factory := TRIP. Classic uses: 79STL := 59S1 from a line-side PT — don't time toward a reclose while an islanded cogenerator holds the line hot; 79STL := NOT 25A1 at the second end of a line — wait for synchronism.

4What blocks a reclose, and what drives lockout

Reclose supervision — the last gate before CLOSE

An open-interval timeout doesn't close the breaker by itself; it must pass 79CLS. With 79CLSD := 0 the condition is checked once, at the instant of timeout; with 79CLSD > 0 the relay waits up to that window (OFF = wait indefinitely). If supervision fails, RCSF pulses one processing interval and (E79 = 1–4) the relay is driven to Lockout — not retried next shot. The SEL-751's E79 := C1–C4 choices invert exactly that: on supervision failure the shot counter increments and the next open interval starts timing — "rotating drum timer" emulation, with lockout only once the intervals run out. Manual examples: 79CLS := 59VP AND 27S1 (hot bus / dead line, first end) and 79CLS := 25A1 with 79CLSD := 1.00 s (give slipping voltages a window to reach synchronism, second end).

5Sequence coordination with a downstream recloser

A feeder relay upstream of a line recloser has a problem: its fast-set elements can overreach and trip for faults the recloser is already clearing. 79SEQ lets the relay count the recloser's operations without tripping: with no trip present and the breaker closed, an overcurrent pickup named in 79SEQ asserting for at least 1.25 cycles and then dropping out means a downstream device cleared the fault — so the shot counter increments anyway and the reset timer reloads with 79RSD. The state doesn't change; the counter can run past last shot, up to shot = 4.

The manual's worked example: recloser set for two fast then two slow operations; relay trip equation TR := 51P1T AND (SH0 OR SH1) OR 51AT OR 51BT OR 51CT. After two fast recloser operations the shot counter sits at 2, SH0/SH1 are gone, and the faster 51P1T is disarmed — in step with the recloser disabling its own fast curve. The refinement 79SEQ := 79RS AND 51P1P AND SH0 stops the counter at shot = 1, so a coincident fault between relay and recloser still gets one reclose instead of instant lockout. Set 79RSD long enough that the counter doesn't reset mid-recloser-sequence.

Operator controls — the recloser control's front panel is an operating device

  • RECLOSE ENABLED — auto-reclosing on/off. Factory drive-to-lockout logic on both platforms: a trip, or the recloser opening, while reclose is disabled → lockout. One shot to lockout.
  • HOT LINE TAG — the line-crew safety control. While ON, no closing of any kind: CLOSE pushbutton, serial CLOSE command, and auto-reclosing are blocked, and a trip or recloser opening drives lockout. On the 651R it overrides RECLOSE ENABLED; in the unlatch-close logic hot line tag and the capacitor monitor are "preeminent." Not a substitute for physical tagging — the control-side half of hot-line work.
  • FAST CURVE ENABLED (651R) — turns fast curves off; factory skip-shot logic then jumps the counter past the fast shots so you get only the set number of delay-curve trips (§7).
  • LOCK / PUSHBUTTONS LOCKED — freezes the other pushbuttons; CLOSE is inoperative, serial CLOSE and auto-reclosing still work, TRIP always works.
  • TRIP pushbutton — trips and goes to lockout. The recloser's yellow operating handle does the same (651R via a qualified 79DTL3X term on interfaces that report it).
  • No standing closes: pushbutton/serial CLOSE pulse one processing interval and CL is rising-edge triggered — toggling LOCK or HOT LINE TAG never releases a queued surprise close.

The battery system (SEL-351RS specifics)

  • The 12 V battery powers the control and trip/close capacitors when ac is dead; the charger runs constant-current, fast, and float modes (plus a < 15 s Cap Charge mode after any operation). CHRGG/DISCHG report state; BTFAIL blocks reclosing via 79CLS. Automatic load test ~every 24 h: below 10.5 V at start (or 11 V during) fails it — DTFAIL, BATTERY PROBLEM LED. With batteries out, ac alone can still trip/close — but ac sags during the very fault you need to clear; the control rides through 0.5 s of total power loss and can still trip within it.
  • Sleep/wake: on ac loss a countdown (PWRDN_AC, default 180 min) runs; at one minute left TOSLP asserts (usable in a trip equation to open the recloser before dying, isolating the downstream section for restoration). The WAKE UP pushbutton revives it for PWRDN_WU (default 20 min).

7Fast vs delayed curves — fuse saving across the shots

The classic sequence is two fast, two delayed. Fast shots trip below the lateral fuses' minimum-melt curves — a temporary fault anywhere, even on a fused lateral, clears and recloses without losing a fuse. If the fault persists, the control switches to the delayed curve, which sits above the fuse: a permanent lateral fault now blows its fuse, only that lateral stays out, and the recloser recloses successfully and resets.

How each platform switches curves

  • SEL-351RS (EZ settings): Min. trip sets pickups; Fast curve = 51P1T, Delay curve = 51P2T. Operations fast curve (OPPH) picks how many trips use fast — the logic ORs the corresponding SH0…SH4 bits into OCP, which torque-controls 51P1T; Operations to lockout (OPLKPH) sets total trips. Keyed to the shot counter the same way: High-current trip (50P2T, armed from a chosen trip number, e.g. HITRPH := 3 → trips 3+) and High-current lockout (a fault above 50P1/50P5 when tripping goes straight to lockout). The cold load pickup scheme disables fast curves and raises the delay curve's effective min trip (50P5P = 51P2P × multiple) without shifting the curve — coordination preserved while inrush decays.
  • SEL-651R-2 (dual-characteristic elements): each 51 element carries two complete characteristics, J and K (own pickup, curve, time dial, CT/MR), selected live by the 51__SW equation → bit 51__S (0 = J, 1 = K). Factory: J is fast (phase curve A, ground 1), K is delay (phase C, ground 13), with 51PSW := NOT(LT04) OR (MV01 <= 79SH3P) — delay once the shot count reaches the fast-trip count (MV01 := 2), or whenever FAST CURVE ENABLED is off. A switch request is ignored while the element is picked up — the curve can't change mid-fault. Factory 79SKP3P accelerates the counter past the fast shots when fast curves are disabled (two delay trips with the right interval, not four). Curves: U1–U5, C1–C5, and traditional recloser curves (old letters A, B, C… cross-referenced to new numbers 101–165; TD 0.10–30.00; no EM-reset emulation on recloser curves).

8Single-phase tripping and reclosing (SEL-651R-2)

With a single-phase-trip-capable recloser (each pole has its own trip/close coil), the 651R can interrupt only the faulted phase and keep the other two alive — "especially applicable in rural areas." Two settings control the split:

  • BKTYP (Global): 1 = single-phase recloser, 3 = three-phase — determines whether per-pole statuses 52AA/52AB/52AC or a single 52A3P are derived.
  • ESPB (Group): Y enables single-phase mode — three complete, independent reclosing relays, one per phase. Every 79 setting and bit exists per phase: 79RIA/B/C, 79RSA/79CYA/79LOA, SH0A…SH4A, CLOSEA, RCSFA…; with ESPB := N one reclosing relay runs all three poles under the …3P names. Trips follow suit: per-phase TRA/TRB/TRC, with TR3P/TR3X for conditions that must always trip all three poles.
  • Lockout policy is a scheme choice: single-phase trip/reclose can pair with three-phase lockout or single-phase lockout, per connected loads. Setting any one 52A_x := 0 defeats close/reclose logic for all three phases.

The SEL-351RS reaches the same goal from the other end: it is a per-phase device — one Kestrel per single-phase recloser — so "single-phase reclosing" is three independent controls on the structure.

9Operations & gotchas

  • The 79 is only as honest as 52A. The state machine keys off the SELOGIC breaker-status equation (52A := IN101 from a 52a auxiliary — you must assign it). Slow 52a + instantaneous tripping is why factory 79RIS includes OR 79CY, and why 79RI := NOT 52A schemes may need ULCL := 0 so CLOSE isn't unlatched before the breaker really closed (anti-pump covers the brief TRIP+CLOSE overlap). 52A := 0 or NA kills both the close logic and the reclosing relay.
  • Manual close ≠ reclose. Closes via CLOSE command, pushbutton, or CL go through the same close logic but are not shots; from lockout they're qualified by 79RSLD before the relay rearms. CLOSE seals in until ULCL, 52A, or close failure (CF) unlatches it; default OUT102 = CLOSE on the 751/751A.
  • Defeated ≠ locked out. With E79 := OFF (N on the 751; or 79OI1 zero/OFF) all three state bits and all shot bits force to 0, both LEDs dark — SCADA points mapped to 79RS/79LO read false, which is not "in lockout." The close logic still works.
  • Settings changes bite mid-sequence. Any settings or group change drives the shot counter to last shot and loads 79RSLD; if timing an open interval, the relay goes straight to lockout. Don't push settings mid-storm.
  • Units differ by platform. 751/751A open intervals/reset times are in seconds (0–3000, 0 = defeated); 351RS/651R in cycles (OFF, 12–999999, OFF = defeated). A "300" copied across is 5 minutes on one, 5 seconds on the other.
  • Underfrequency and reclosing don't mix. Load-shed trips should drive lockout (79DTL := TRIP AND 81D1T; factory behavior on the 351RS) — reclosing shed load defeats the shed.
  • DAC interaction. Automation keys on 79LO and operation counts; hot line tag, reclose-disable, and fast-curve toggles all change what the scheme sees. Read the DAC pages (how-it-decides, operating-it) before changing shot counts on a DAC feeder.
  • No built-in 79? AG9405 builds full recloser functions (single-shot, two-shot, single-shot/two-breaker) purely from SELOGIC in the SEL-321; AG9903 is the pattern book for switch-selected high-speed vs delayed reclosing with hot-bus/dead-line and sync supervision on the SEL-351.
  • Testing: watch TARGET for shot/state bits, OPTMN/RSTMN for which timer is running, and remember 79DTL's 1-second dropout when pulse-testing lockout conditions.
